# 雷达绕障缓存

保存地图时，`JsonRadarMapStore` 为每个线段端点沿外向延长线生成一个绕障点。默认延长 3 米；3 米内遇到其他障碍时，取原端点到最近交点的中点。角色按点处理，不使用通行宽度，也不按毫米取整。共用端点的零间隙不生成点，重合候选点合并。

`NavigationCache` 保存规则版本、障碍几何摘要、内容校验、点坐标和无向连接的长度。地图外层保持版本 1，兼容旧客户端读取障碍线。旧地图或过期/损坏缓存加载时会在内存重建；普通读取不回写文件，避免覆盖编辑中的地图。保存地图会将有效缓存一并原子写入。

运行时，移动导航与目标距离评分共享同一地图版本的图。每次路径查询只接入起终点并运行 A*，不重建或复制静态连接。保留原有绕行距离上限、到点处理和直线接近行为。旧圆周候选点及候选点数量上限已删除。

## 更新已有地图

在仓库根目录执行预览：

```powershell
dotnet run --project tools/RadarMapCache -- 'C:\path\config\radar-maps'
```

加 `--apply` 更新：

```powershell
dotnet run --project tools/RadarMapCache -- 'C:\path\config\radar-maps' --apply
```

工具只处理指定目录下以 MapId 命名的 JSON 文件，只添加或替换 `NavigationCache`，保留原障碍线、时间字段及其他字段。每个文件原子替换前核对源内容是否变化，并将原文件备份到 `.navigation-cache-backups/<时间>/`。有效缓存不重复写入。工具直接编译引用生产几何、建图和地图加载代码，不需要启动桌面客户端。

## 验证

`Roadhog.Tests` 中 `radar` 过滤包含端点方向、最近交点、中点、毫米及更小间隙、共享端点、封闭障碍、A* 最短路独立校验、100 线段性能样本、缓存损坏/失效、旧图兼容、原子保存和运行时地图刷新测试。

现场回放夹具 `radar-script2-20261101.json` 保留原 47 条线段。最后三条相连且相交，围住日志中 `(693.508, 2967.151)` 的角色位置。回放验证内部返回 `no_route`，外部可以绕行；更换寻路算法不应制造穿过封闭障碍的路线。
