# 统一技能栏释放

主技能释放统一使用技能栏引擎。设置页只显示一棵执行树，刷新按钮按主栏和 Alt 栏实际放置的技能等级更新该树及起手、维护、团队和精灵相关选择。起手、维护、精灵召唤、宠物维护、DOT 和普通攻击插入继续使用共用流程。

旧账号和方案 JSON 仍可读取。加载或启动时在配置副本中迁移，原文件不会因为读取被重写；正常保存才写入新版模式。保留旧技能字段作为兼容档案：

- 已有新版树始终优先，明确使用新版而树为空时保持为空。
- 只有旧版且新版树为空时，按原自动树、系统树或有效手动映射的顺序生成新版树，保留连续技结构。
- 旧调度不执行的 DP 根不会自动加入攻击树，DP 维护规则保留。
- 迁移不猜测技能等级或按键。运行时仍要求主栏、Alt 栏或可确认的连续技栏位；未绑定技能通过现有诊断跳过。

旧主攻击调度、触发前缀和条件技能抢断旧连续技的策略已退役。新版按官方可用状态选择条件技能，连续技优先，普通技能沿用冷却确认；没有有效召唤宠物时，精灵命令在选择、重试和发键前均被抑制。

验证必须使用隔离的 `RoadhogDesktopScriptRoot`。测试程序提供 `--skill-release-migration-audit <accounts.json> <profiles目录> <审计输出目录>`：仅对副本执行加载、保存和重载，核对已有新版树、旧字段和其他配置不变，并检查源文件哈希保持不变。自动测试不能代替真实客户端的技能状态和硬件输入验证。
