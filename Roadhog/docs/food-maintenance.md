# 自动饮品、食物维护

维护页有两个独立的开关：`AutoDrinkEnabled`、`AutoFoodEnabled`，默认开启（旧配置缺少字段时也开启，明确保存的关闭选择仍保留）；均随账号配置保存和克隆。

挂机与半自动统一：观察到战斗后，在战斗和拾取结束的安全窗口检查；取消启动及 910 秒定时检查。两个开关都关闭时不执行检查。状态一次读取用于两类判断，已有同类状态时不额外执行使用前的完整安全检查。
同类状态存在就跳过；缺少同类状态且背包有可用物品时，按使用技能等级升序选择，最低等级为 3（中级）。
同时要求角色满足物品需求等级；同等级按需求等级、模板 ID、格子和实例 ID 稳定排序。

## 技能栏优先

两类开关旁各有可多选下拉框。展开时自动读取当前主栏、Alt 栏及背包，列出中级以上对应料理和按键。
配置保存 `PreferredDrinks` / `PreferredFoods` 的物品模板 ID 和名称，不保存旧格子、实例或按键。
未在当前栏位的已选项保留显示，可以取消勾选。保存配置后重启该账号脚本生效。

使用时匹配当前栏位的物品模板、实例、角色需求等级和勾选项；多个勾选项仍按低等级优先。
没有可用勾选项时按原规则从背包选择。快捷键沿用技能绑定约定：主栏 1–0、减号、等号，Alt 栏对应 Num1–Num0、Num+、Num-。
按键前再次核对当前页和具体格子内容；页码、物品或格子改变就取消本次，不按保存的旧位置。
按键后等待同类状态出现；未确认时记录失败并等待重试，不立即从背包再吃一件。

`QuickbarSlotSnapshot` 增加物品模板/实例字段，仍走原有 quickbar 原子捕获与正式快照发布。
只对物品类型 1 填充，技能 ID 仍仅用于类型 21，其他技能消费者保持不变。
`QuickbarDecoder` 交叉验证表项模板/实例与 UI 控件，并复读全部捕获字段。
依据本地导出 `sub_180274520` / `sub_1802756F0`：表项 +4/+8 为模板/实例，控件 +960/+952 为模板/实例。
2026-10-06 在 Tone 主栏第 9 格只读核对了物品 164000094、实例 3351003569 的对应关系；当时支持的两栏尚未放置料理。

## 分类依据

分类链路为：背包物品静态定义的使用技能名称 → `client_skills.xml` → `conflict_id`。

| 类别 | conflict_id | 样本物品 | 使用状态 |
|---|---|---|---|
| 饮品 | 21 | 中级至最上级精华 | 10044 |
| 饮品 | 21 | 普雷沙鸡尾酒 | 10062 |
| 食物 | 22 | 中级至最上级精气 | 10051 |
| 食物 | 22 | 美味的弥内寿司 | 10097 |

类别判断不依赖中文名称或物品 ID 白名单，也不要求同类料理效果一致。
自身状态按状态 ID 映射同一 conflict_id，不能使用 `IsBuffCategory` 过滤（实测料理 Category 为 3）。

## 已验证的本地适配器数据

2026-10-06，通过 Tone 的背包及客户端静态记录验证。读取继续使用现有静态索引和解压接口。
静态记录以模板 ID 回校身份；偏移仅留在 `AionVmmGameApi.Food.cs`，不进入业务层。

| 相对记录字段 | 类型 | 含义 |
|---|---|---|
| 280 | UTF-16 字符串指针 | 使用技能名称 |
| 328 | uint | 物品使用组，21/22 为料理候选，最终分类再查技能表 |
| 493 | byte | 需求等级 |
| 498 | byte | 使用技能等级 |

中级精华/精气为等级 3、需求 30；上级为 4/40；最上级为 5/50。
鸡尾酒为 4/40，寿司为 3/30，最下级精华为 1/10；物品品质不用于排序。

`InventoryItemSnapshot.Food` 属于现有 inventory 正式快照，具备独立字段有效性。
读取失败保留原有定义，有效数量等字段仍可更新；有效非料理记录发布 null。
冷启动不发布元数据不完整的新物品；没有新增业务层失败回退或第二份缓存。

## 输入及确认

- 死亡/复活、过图/换线、战斗目标、敌人攻击自己或宠物、拾取、采集、清包、交易和弹窗均阻止使用。
- 准备动作先停止移动、跳跃辅助、预瞄和寻路轮询，与账号主循环串行执行。
- 打开背包后按实例 ID、模板 ID、数量定位；鼠标到位后验证悬停、坐标、物品和状态。
- 右键一次，等待对应类别状态出现；不以按键发出或数量减少单独判定成功。
- 期间角色掉血、身份/地图/频道改变或重新进入战斗即中断。
- 快捷键使用不打开背包；背包方式用完关闭本流程打开的背包，原本已打开的背包保持原状；停止时释放鼠标。
- 单次流程最多 12 秒，异常记录 `food.attempt_unconfirmed`，失败类别 30 秒后才可重新检查，不阻挡本轮另一类别。
- 确认成功记录 `food.used`，包含物品、类别、等级、使用技能及账号。
