# 拍卖行测试入口

清包页的“测试拍卖行”是手动诊断流程，共用背包测试互斥锁和运行器的手动输入协调。它不提交上架、不领取金币、不接入自动清包调度。关闭设置窗口会取消测试并释放输入。

流程验证目标NPC、NPC对话、委托交易按钮、拍卖行、三个页签；读取待结算金额；使用拍卖行名单中首个匹配的背包物品检查查价和上架弹窗；取消弹窗，空格关闭拍卖行。没有匹配物品时只检查窗口和页签并明确报告。

查价方式按物品保存，字段 `priceLookupMethod`：

- `Manual`：保留手动单价。旧配置默认这个值，旧单价不变。
- `DialogMinimum`：读上架弹窗的市场最低价。
- `SearchCalculation`：先在目录页清除旧查询，右键物品并搜索，读取对应报价列表；算法尚未定义，只报告读取结果，不推算出售价格。

非手动方式的价格格只读、灰显为“—”，手动价格不参与校验、编辑保存或定价。原手动值仅作为配置保留，切回手动时恢复；`EffectiveUnitPrice` 在非手动模式始终为 null。

所有业务读取走 `IRoadhogSnapshotReader.ReadAuctionHouseAsync`，通道 `auction_house` 注册为 Stable。适配器沿用现有读、验证、发布、会话失效机制。业务仅轮询动作结果，不处理读取质量。动作未确认就超时停止，不盲目重复提交。

适配器依据 `aion202609091125.json`，在账号2（Tone）实测：对话132、拍卖行152、上架编辑310；根表 Game.dll+0xD63990。UI几何、可见/禁用状态、链表、文本长度、列表边界和捕获前后字段一致性均验证。价格和数量来自本次窗口状态，不使用固定点击坐标。字符串读取只识别已验证的文本getter布局，不执行客户端函数。

NPC身份以名称“摩比隆”，或目标NPC模板的标题资源键 `STR_NPCTITLE_Middleman`（交易中介）判定；后者通过 client_npcs.xml 查询，连同目标服务端ID发布并与当前选中目标匹配。实机验证了摩比隆分支，其他名字分支由测试覆盖，尚未切换到另一名NPC实测。

市场最低价控件为 `min_price_view`；`min_unit_price_view` 是允许价格下限，不是市场最低报价。列表包含空槽，必须按有效物品条目计数。结算加载标记清零时不使用残留金额。上架弹窗不向测试流程提供确认按钮，结算页不提供领取按钮。

验证：配置迁移/序列化、独立保存及回滚、列显示、正式快照保留及会话隔离、关闭窗口有效空数据、短读/变化捕获拒绝、动作状态推进、角色变化阻止点击、取消释放输入；实机日志与界面预览保存在 `.tmp/auction-ui-live`、`.tmp/auction-ui-preview`。
