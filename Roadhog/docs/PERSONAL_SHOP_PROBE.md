打开个人摊位（Y）→ 打开背包（I）→ 按清包“出售”规则筛选 → 逐件右键 → 输入单价 1 → 确认登记 → 关闭遮挡按钮的背包 → 开始出售。

清包页“清理物品类型”右侧提供 **测试摆摊** 按钮。点击后使用当前页面的出售规则和白／黑名单，无须先保存；整叠登记、固定单价 1，一次最多 10 项，完成后保持出售。仅新增手动测试入口，不接入后台自动清包或自动补货。

正式调用链：`AccountSettingsForm` → `RoadhogRuntime.TestPersonalShopAsync` → `PersonalShopSequence`。`personal_shop` 与 `personal_shop_cursor` 均注册为 Stable 官方快照通道，原始读取和一致性校验位于 `AionVmmGameApi.PersonalShop` / `PersonalShopDecoder`。失败读取由 provider 保留上次官方快照，首次读取等待有效发布。业务层只使用已发布值。

按钮执行时禁用，关闭窗口会取消并释放输入；与脚本、切频道测试和“测试移动”共用手动输入互斥。已经出售时不再点击；已有登记或价格输入框时提示先取消。重新测试可在停止出售后，打开摊位，对已登记物品右键逐件撤下。

## 最新游戏数据与补齐字段

来源：用户提供的 `Desktop\aion\aion202609091125.json` 与同目录 Game.dll；通过账号 2 实机核对。

| 数据 | 位置 / 含义 |
| --- | --- |
| Dialog 表 | `Game.dll + 0xD63990` |
| 个人摊位 | 表索引 168；指针位于 `Game.dll + 0xD63ED0` |
| 单价弹窗 / 单价数量弹窗 | 表索引 169 / 170 |
| 可见性 | Widget `+0x28` bit 0；可用性 bit 1 |
| 摊位开始标志 | 摊位 `+0x4D8`：实测 0 → 1 |
| 流程状态 | 摊位 `+0x528`：实测编辑为 3，出售为 1；其他枚举尚未验证 |
| 当前登记实例 ID | 摊位 `+0x510` |
| 当前登记弹窗指针 | 摊位 `+0x520` |
| 出售列表 | 摊位 `+0x4F0`；列表 `+0x368/+0x370` 为指针数组 begin/end，最多 10 槽 |
| 已登记实例 ID | UI Item `+0xA0`，可映射背包实例 |
| 已登记模板 ID | UI Item `+0xA8`，本次与背包 TemplateId 逐项一致 |
| 已登记数量 | UI Item `+0xB0`，uint64 |
| 单价树 | 摊位 `+0x4E0` 的树头；节点 `+0x20` 为实例 ID，`+0x28` 为 uint64 单价 |
| 弹窗价格模式 | 弹窗 `+0x5BC`（1468）；本流程要求模式 0（单价） |
| 弹窗单价 / 总价 | `+0x5C0 / +0x5C8`（1472 / 1480），uint64 |
| 弹窗数量 | `+0x5E0`（1504），uint64 |
| 输入控件 / 确认按钮 | 弹窗可见子树名称 `price` / `ok` |
| 开始 / 停止按钮 | 摊位 `+0x500 / +0x508`，名称 `start` / `stop` |

价格依据：`sub_18022B460` 从弹窗的单价与数量成员分别取值，再把单价存入摊位树；`sub_18022BEA0` 按实例 ID 查树并返回节点 `+0x28`。本次输入 1 后，弹窗与已登记树均读回 1。

按钮坐标不是直接取 Widget 的 `+0x58/+0x60`。子控件须累加祖先 bounds 原点与 client 原点（`+0x78/+0x80`），最后加自身宽高的一半。背包格子还需要结合列表的行列数、格宽高、间距和 padding。

实机发现：重新打开背包后，如果鼠标停在原地，hover 索引可能仍为空。探针会先移开少许再移回，再核对列表 `+0x3F0` 对应的物品实例 ID；匹配失败时在右键前停止。

## 使用

构建隔离产物，避免构建钩子刷新正在运行的桌面程序：

```powershell
dotnet build Roadhog.Tests\Roadhog.Tests.csproj -c ShopVerify -p:RoadhogDesktopScriptRoot=C:\D\Develop\MyCode\Tool\.tmp\personal-shop-live\runtime-sink
```

只读检查（默认不连接 KMBox、不发送输入）：

```powershell
Roadhog.Tests\bin\ShopVerify\net8.0-windows\Roadhog.Tests.exe --personal-shop-probe --root=C:\Users\GoldGiven\Desktop\script\2
```

按本次授权执行单价 1 的测试：

```powershell
Roadhog.Tests\bin\ShopVerify\net8.0-windows\Roadhog.Tests.exe --personal-shop-probe --root=C:\Users\GoldGiven\Desktop\script\2 --execute --character=Tone --unit-price=1
```

- 从指定目录实时加载账号、KMBox 与清包名单，复用 `SelectSellRegistrationItems`，只选择启用的出售规则，并保留白名单、黑名单和已装备物品过滤。
- 使用保存的设备映射，校验 USB 绑定仍存在，并取得设备租约；发现设备占用即停止。
- 已在出售、已有登记、已有价格弹窗或没有候选时均不点击；不会再次点击开始／停止开关。
- 一次最多登记 10 项，输出剩余候选数；不自动撤摊、补货或继续下一批。
- 点击确认前核对待登记实例 ID、单价模式、单价 1、总价及整叠数量；开始前再次核对整份登记清单。
- 坐标越界、未命中目标、读数不足或动作未确认时停止，不盲重试；退出释放按键、鼠标及设备租约。
- 单价固定为 1，只接受参数 `--unit-price=1`，不使用默认价格悄悄出售。
