统一清包流程改用 `NpcSaleSequence` 和独立的 `npc_trade` 正式快照。新增读取复用 JSON 中既有 DlgTrade 布局：`2CC800 / 2CCED0 / 2D01E0`，不调用客户端函数。商人身份、出售模式、列表物品身份和数量、控件位置、外来弹窗均纳入校验；背包无需移动，确认后同时验证物品和金币变化。未确认的交易不会重复提交。旧独立清包入口保留兼容行为。
