# 其他 → 魔石兑换

靠近比洛加，在账号设置的“其他 → 魔石兑换”点击“兑换魔石”。选 NPC 前先按一次 F1，随后按 F8 选择固定 NPC 比洛加（最多尝试30次，核对实际目标），再按 C 对话。F1 只在这次选 NPC 开始前按一次，不随 F8 重试重复按。按钮在运行时变为“停止兑换”，再次点击即可停止。该任务与本账号挂机、砸装备及其他手动输入互斥。轮流执行两种批量兑换，一种材料不足后继续另一种，两种都不足时正常结束。

| 任务 | 白色魔石，每种 10 个 | 奖励 |
|---|---|---|
| 4113 比洛加的魔石袋 | 167000354 生命力+60、167000356 命中+20、167000361 盾牌防御+20 | 188051284 魔石袋 ×1 |
| 4114 比洛加的魔石包袱 | 167000355 精神力+60、167000357 回避+12、167000360 武器防御+20 | 188051283 魔石包袱 ×1 |

只计背包内 `ItemType=24, QualityRank=1` 的上述模板，支持分堆求和。其他白色魔石、绿色魔石及单个交换任务不参与。当前支持实机验证的比洛加两项任务，不扩展到其他等级兑换。

## 执行及停止

按 C 打开 NPC → 点击 `QuestSelect4113/4114` 批量任务 → 接受 → 交出魔石 → 确认。实机证明**交出时扣料，确认时才发奖励**。交出后核对三个模板各减少 10，确认后核对正确奖励增加 1，再进入下一轮。提交超时不会自动重发。

“停止兑换”或关闭设置窗口取消任务并释放输入。若已交出材料且奖励页仍在，重新开始保留当前 NPC 对话，优先领取这一份奖励，即使剩余材料不足；恢复分支以奖励增加 1、剩余材料不再减少为准，不假造前一轮的消耗基线。角色死亡、目标改变、其他任务页面、遮挡或奖励不符会终止本次操作并报告原因。

菜单为 `PageType=5, PageId=10, QuestId=0`；接受页面为普通选择页 `PageType=1`，接受后 `PageId=1003, PageName=quest_accept_1`；交出后为 `PageType=4, PageId=5, PageName=select_quest_reward1`。接受和交出都可用 select1，必须同时区别任务身份与文本。“基本奖励”按钮没有 href，仅展示；底部“取消”和右上关闭都可命名 cancel，应按具体控件区分。

诊断另核对 Quest 解压缓存 `GameBase+0x938B0C`：8槽、每槽10080字节、首DWORD为QuestId；匹配记录的 `+248..260` 是材料模板，`+264..276` 是数量。此缓存仅用于验证固定任务表，不是生产入口，未命中不代表没有材料要求。
