# 其他页：装备强化和魔石镶嵌

在账号设置的“组队”后增加“其他”。刷新背包后勾选装备，再点选装备行，为每件装备独立勾选允许使用的强化石等级，或选择一种魔石。同名装备按实例 ID 区分。选择随账号设置保存，刷新保留已选但当前不在背包的项目。强化石从勾选等级中由低到高使用，同等级按背包位置选择。

全部配好后点击顶部“一键执行”：先校验所有材料配置，然后按装备自身等级从低到高执行；同等级先处理当前强化值较低的装备。两个等级均相同时先强化、后镶嵌，再按背包位置和实例 ID 稳定排序。每次消耗一颗石头并等待结算后，重新读取实际等级排序；失败掉级会重新获得优先级。强化、魔石任务共同参与排序，只勾选一组时仅执行该组。装备达到 +10 或普通孔满即完成对应任务，缺料跳过并汇总提示。等级读取失败时由 provider 保留正式快照，不将未知等级当作 0；没有可用装备等级则不开始操作。

全部任务完成后，每 1500ms 按一次空格（短按 60ms），持续到点击“停止”或关闭设置窗口；仍有任务缺料或发生异常时不启动空格循环。空格阶段继续持有本账号手动输入互斥，停止通过现有 RPC 取消传播到 worker，释放空格键和输入互斥。

强化目标固定 +10；魔石目标为装备普通魔石孔满。当前版本不操作穿戴装备、不增加孔数、不替换已镶嵌魔石、不配置武器合成副武器孔或辅助强化道具。普通孔与合成副武器孔是客户端不同的目标选择，不能将两者混成一个计数。

任务只在手动启动时执行，与该账号挂机/其他手动输入互斥；使用现有账号 worker RPC 和设备租约。停止或关闭设置窗口取消任务并释放按键。已提交到游戏的读条可能继续结算。中途取消后若窗口仍开着，关闭该窗口后才能重新开始。

每轮：打开背包 -> 核对鼠标悬停的石头实例 -> 右键 -> 核对装备实例 -> 左键 -> 核对第一层材料/装备 -> 确认 -> 核对属于该编辑窗口的第二层消息框 -> 确认 -> 固定等 6000ms -> 等编辑/读条窗口关闭 -> 确认材料消耗 -> 读取真实等级/孔位。失败后按实际状态继续；不按点击次数推算成功。逐件缺料跳过，陌生弹窗、身份变化、操作结果超时停止，不盲目重复确认。
