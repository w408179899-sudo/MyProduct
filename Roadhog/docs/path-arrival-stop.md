# 路径到点松键

路径跟随继续使用当前点的水平坐标距离和调用方传入的精度：`distance <= reachDistance`。
不预测速度，不添加提前量，也不改变返回途中防御、清怪、宠物、维护、死亡和停止检查。

位置轮询默认间隔为 50ms（`AION_PATH_FOLLOW_TICK_MS`）。使用已有的正式玩家快照确认到点后，
调用独立的前进键释放流程，不再等待挂机主循环。角度数据缺失不会影响坐标到点判断。
实际松键仍包含快照读取及输入设备当前命令的处理时间，50ms 不是端到端延迟保证。

- 每个 worker 状态各自串行处理 W 按下、松开和路径目标切换。
- 到点标记阻止旧转向/移动操作重新按 W；主流程负责下一点、战斗和维护决策。
- 目标版本和轮询实例共同限定停止信号的作用范围，旧信号不能松开新路径段的 W。
- 成功松键后更新移动状态；失败保留到点标记并在后续轮询重试。
- 到点流程只释放 W，保留原来的右键、转向和主流程职责。退出时仍由 worker 清理输入。
- 该机制位于共用路径跟随器，手动路径、复活返回、启动返回、路径打怪和雷达中间点共用。

实现：`StationaryCombatController.PathArrival.cs`；并发回归：`Roadhog.Tests/PathArrivalTests.cs`。
定向测试使用 `--test-filter=path arrival`，并覆盖既有启动/死亡恢复、路径打怪、手动路径、
雷达到点确认及战后返回测试。构建时通过 `RoadhogDesktopScriptRoot` 指向隔离目录，避免自动部署桌面实例。
