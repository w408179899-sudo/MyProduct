# 动态复活确认

自动死亡恢复的首次点击和重试点击都读取 `revive_ui` 正式快照，使用与背包相同的 `FeedbackMouseMover` 移动到确认按钮中心。移动后重新核对角色仍死亡、角色身份、窗口实例、按钮位置和鼠标位置，再点击一次。点击后仍由原死亡恢复流程等待角色存活，再执行恢复和复活路径。

窗口未显示、按钮隐藏/禁用/越界、窗口移动或被其他复活/消息确认窗口阻挡时等待；不退回固定坐标。此版本自动点击普通死亡复活窗口，不自动接受他人施放复活的确认框。

`DeathReviveClickX/Y` 旧配置保留用于转向失败后的鼠标重置，设置页名称改为“转向重置坐标”；死亡复活不再使用它，也不再轮换三组预设坐标。
