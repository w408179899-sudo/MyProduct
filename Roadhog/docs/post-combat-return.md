# 原地打怪：战斗结束回原点

总览“选怪与拾取”增加一个“战斗结束回原点”勾选，默认关闭；旁边“距离超过”默认 5 米，可填写非负数和小数。取消勾选保留已填距离。账号和方案都保存这两个值，旧配置缺少字段时按关闭、5 米处理。保存后通过账号 RPC 通知正在运行的 worker，下次战后判断使用新设置；关闭选项会取消尚未完成的战后回程。

仅在自定义打怪的原地模式生效。确认当前怪死亡后，先完成已启用的拾取及战后收尾，再根据本轮最新角色位置计算到原点的水平距离：严格超过填写距离且离原点超过 2 米才开始回程；等于或低于填写距离时继续正常选怪。填 0 表示每次战后都尝试返回，已经在原点 2 米内则无需移动。

返程开始后持续到原点 2 米内，期间普通怪、较近主动怪、智能选怪和采集不会提前接走流程；原有自卫和队伍保护可以接战，战斗与拾取结束后继续这次回程。死亡、复活路线、清包和停止清除旧请求。路径打怪、复活途中清怪和单纯目标丢失不触发此功能。角色还在战斗时不会因为超过设置距离而中断当前怪。

原点沿用现有规则，优先取复活路径最后一个点。原有挂机半径和“没怪回中心”仍独立生效；例如战后处于 5 米内但没有可打目标，勾选“没怪回中心”时仍会返回。

定向回归覆盖距离边界、自定义小数、关闭选项、拾取开启/关闭/不可拾取、拾取改变角色位置、返程反击、到点恢复选怪、运行中设置更新与账号隔离、生命周期清理，以及账号/方案保存和总览布局。构建输出使用临时 script-sink；模拟验证不代表已部署或游戏内实测。
