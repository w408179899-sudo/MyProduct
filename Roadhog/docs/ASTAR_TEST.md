# A* 独立寻路测试

账号设置 → **A*测试**。该页独立于挂机、追怪、清包和原有雷达绕障。

## 使用

1. 加载角色所在地图的导航文件；整图使用 `.astar.bin` / `.astar.bin.gz`，也支持 `.astar.json` / `.astar.json.gz`。
2. 让角色站在要到达的位置，点击目的地行的“设为目的地”，记录 XYZ。
3. 手动把角色移动到同一地图的其他位置，目的地保持不变。
4. 停止本账号挂机和其他手动任务后，点击“启动寻路”：自动读取角色当时的位置作为起点，重新计算路线，成功后立即开始行走。
5. “停止”或关闭设置窗口可取消位置读取、计算及行走。再次启动会读取新的当前位置，重新规划到同一个目的地。

想先离线查看路线，可以手动输入起终点后点“预览路线”；“加载副本样本”会自动生成样本预览，无需连接游戏。“启动寻路”始终重新读取实际起点，不执行旧预览路线。加载另一张整图会清空目的地，需重新记录或输入。

当前位置必须在导航覆盖范围和对应楼层内；无可达路线时只显示原因，不开始移动。路线计算后若角色又走离起点（水平超过 1.5 米或高差超过 1 米），行走检查会拒绝执行。终点为贴合后的导航点，不额外直走到用户输入的任意位置。

显示高度控制只影响俯视图的节点切片（Z ±2 米），不影响三维 A* 计算。橙线显示完整路线。图中空白不一定是墙，也可能不在当前高度切片内。大地图显示可抽样，寻路仍使用完整加载图。

## 模块边界

- `Core/NavigationTests`：只处理显式三维图、端点定位、A*。代价和启发式均为三维距离；不从图片推测通行，不把模型三角形投影为障碍线。
- `Infrastructure/NavigationTests`：加载 JSON 或紧凑二进制（均可 GZip），限制文件/解压大小、节点与边数，拒绝非有限坐标、非法邻居、重合边、截断和尾随数据。
- `AccountSettingsForm.AStarTest.cs`、`AStarTestCanvas.cs`：设置、异步加载/计算、路线展示与命令发送。加载页面本身不启动硬件。
- `Application/NavigationTests`：单次路线顺序执行，地图/频道/死亡/起点/高度/偏离检查。逐点移动，不平滑抄近路，不跳到后面的近邻点。
- 账号后台通过 `IRoadhogRuntime.RunAStarWalkTestAsync` 与现有 RPC 传递请求、进度、取消。复用 `AccountOrchestrator.RunManualInputAsync` 排他任务与现有移动控制器。
- 坐标来自已有 `ReadChannelTransitionAsync` 正式快照；不新增原始内存读取、数据质量回退或共享坐标缓存。

到点阈值：水平 0.35 米、高差 0.75 米。相对目标高度偏差超过 3 米、偏离当前路线段超过 2 米、10 秒未进一步接近、地图/频道变化或死亡会终止测试。单次行走最多 30 分钟，避免远距离测试被原有 3 分钟上限提前中断。每次结束/异常/取消都释放移动并结束路径轮询。每次启动都会重新规划；行走途中不自动跳跃或重新规划，不包含战斗及机关交互。

密集导航点使用 A* 专用的短按移动：复用既有转向控制，W 每次按下后至多等待 25 ms 就松开，再观察正式位置快照。等待下一次位置或重新转向时不持续按 W。普通挂机/路径模块的持续移动方式不变。`astar_test.move.step` 按秒记录位置、目标与短按参数，页面按秒显示水平距离和高差。

2026-11-12 脚本1在 `(907.460,2885.492,260.351)` 到 `(889.903,2902.196,272.043)` 的测试中算出 37 点、43.50 米路线，但连续按 W 在距首点仅 0.69 米时越过目标，日志多次出现约 180° 掉头，最终首点超时。短按修复通过了“松键后才发布下一次位置”的模拟移动回归，仍需该账号实际重试确认。

## 数据格式

```json
{
  "version": 1,
  "mapId": 300100000,
  "name": "地图名称",
  "description": "覆盖范围和限制",
  "nodes": [
    { "position": { "X": 1, "Y": 2, "Z": 3 }, "neighbors": [1] },
    { "position": { "X": 2, "Y": 2, "Z": 3 }, "neighbors": [0] }
  ]
}
```

数组下标为节点 ID，邻居为允许通行的有向边。可双向通行需写入双向连接。节点最多 16,000,000、总连接最多 128,000,000、单节点邻居最多 64。JSON 压缩前后均最多 64 MiB；行走路线最多 20,000 点。

整图二进制格式：小端序，8 字节 ASCII `RHASTAR1`；Int32 版本 `1`；UInt32 地图 ID；Int32 节点数 N、边数 E；两个 .NET BinaryWriter UTF-8 字符串（名称、说明，单个最多 8192 字节）；N 组三个 Float32 的 XYZ；N+1 个 Int32 邻接偏移；E 个 Int32 邻居 ID。偏移从 0 单调增长到 E，单节点偏移跨度最多 64。数量校验在分配数组之前完成，并逐批检查取消；格式不允许尾随字节。二进制文件最大 1 GiB，数组分配另由 N/E 上限约束。

`tools/navigation/import_probe.py` 可将前述离线实验的 `sample_floors.json` 转为此格式；它只转换已有连通关系，不解包客户端：

```powershell
python Roadhog/tools/navigation/import_probe.py --floors C:/D/AionNavigationProbe/20261112-172115/output/sample_floors.json --map-id 300100000 --name IDShulackShip --output C:/D/new-sample.astar.json.gz
```
