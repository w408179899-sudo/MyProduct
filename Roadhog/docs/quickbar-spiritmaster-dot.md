# 新版精灵 DOT 判定

开启精灵专用逻辑时，技能栏可用模式也使用精灵设置里的 DOT 列表。普通根技能即使冷却结束、栏位可用，只要当前目标的正式异常状态快照仍包含该技能 ID 或已学习的异常 ID，就跳过并选择后面的技能；状态消失或换怪后重新允许施放。启动冷却校准候选也遵守这条规则。

DOT 尚未出现时保留新版原有的有限重试。状态出现只停止重复按键，释放确认、卡刀和连续技确认仍由原有实际释放记录及冷却证据决定。连续技子节点沿用旧版语义，不被根技能的 DOT 规则阻断。

学习使用首次成功发送按键前的目标状态基线，同一动作的重试不重置基线；观察期限覆盖该动作的确认截止时间并额外留三秒。其他技能成功发送或观察到不同目标时取消尚未完成的学习，防止把其他技能的异常状态记到这个 DOT 上。已学习的技能与异常 ID 映射保留。

关闭精灵专用逻辑、明确识别为其他职业或没有配置 DOT 根技能时，不启用这项额外状态读取。全部状态读取通过已有 provider 正式快照接口完成。

专项回归：`--test-filter=quickbar spiritmaster dot`。同时回归旧版 `spiritmaster selector`、`spiritmaster dot` 以及 `skill tree release`、维护、卡刀和快照相关测试。
